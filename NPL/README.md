# **Natural Language Processing (NLP)**

## **A. Spacy**

This repository introduces the fundamental concepts of **Natural Language Processing (NLP)** using the Python library **spaCy**.

The goal of this project is to explain how spaCy processes text internally and how its core objects interact to represent linguistic information.

The examples illustrate how raw text can be transformed into structured data suitable for downstream tasks such as information extraction, classification, or text analysis.

---

### Index

1. **NLP Object**. Represents the processing pipeline
2. **Doc Object**. Represents a processed document.
3. **Token Object**. Represents a single unit of text.
4. **Span Object**. Represents a slice of  document.
5. **Lexical Attributes**.
6. **Trained Pipelines**.
