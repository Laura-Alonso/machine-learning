# **Supervised Learning**

## **A. Linear Regression: Theory and Python Implementation**

This repository provides a technical exploration of **linear regression models**, focusing on the mathematical foundations and practical implementation in Python.

The objective of this project is to demonstrate how different regression techniques behave when predicting a continuous target variable using real-world data.

Unlike typical tutorials, this project emphasizes **model mechanics, assumptions, and statistical interpretation**, rather than only implementation steps.
